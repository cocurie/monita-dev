# StrainInspector — ひずみFlexモジュール 出荷検査治具 用テストファーム

## 背景

ひずみFlexモジュールの出荷検査治具（シャント抵抗方式）を使って、Flex基板の4CHすべてにひずみモジュールを接続し、シリアルモニタから対話的に測定・ゼロ点補正できるようにするための専用ファーム。

治具の設計は `【7】Monita/開発/開発メモ/20260824_ひずみFlex出荷検査治具_基板設計.md` を参照。

## ベース

`case01_Flex/v3.20/src/main.cpp` の以下の関数をほぼそのまま踏襲している。

- `muxSelect()` / `tca9534Configure()` — TCA9534経由のCH切替（SN74LV4052）
- `hxBegin()` / `hxReadAvg()` / `hxRead()` — HX711の初期化・2段平均＋メジアン読み取り
- `hxTareWithTimeout()` — タイムアウト付きタレ

v3.20から**取り除いたもの**: 通信（Sigfox/BLE/LoRa）、スリープ・WDT、RGB LED、DS3231、電池電圧、CH_ASSIGN可変（本ファームは4CH固定でHX711のみ）、フラッシュへのタレオフセット保存（電源を切ると失われる。RAM保持のみ）。

## コマンド

シリアルモニタ（115200bps）から1文字を送信する。

| コマンド | 動作 |
|---|---|
| `0` | 4CH測定（単発）。結果をµεでシリアルに表示 |
| `8` | 4CHゼロ点補正（タレ）。現在値を **0 µε** とする |
| `9` | 状態確認。タレオフセット・**現在のゼロ点基準（µε）**・直近測定値・直近応答状況をキャッシュから表示（**ハードウェアへはアクセスしない**ため即座に返る） |
| `s` | ゼロ点を**任意のµε値**へシフト（4CH一括、同じ値を適用）。送信後「ゼロ点としたいµε値を入力してください」と表示されるので、数値（負数・小数可、例: `-1993`）を入力してEnter |

起動時に使い方バナーとTCA9534の応答状況を表示する。

### `s`（ゼロ点シフト）の使いどころ

出荷検査治具の②負方向基板のように、**モジュール本来のゼロではなく、あるシャント位置を基準点として扱いたい場合**に使う。例えば基準点が理論上 −1993 µε の位置にある場合、`s` → `-1993` → Enter とすると、その瞬間の生値が −1993 µε として記録され、以降の測定値はその基準からの相対値になる。

内部的には `8`（タレ）と同じ仕組みで、目標値だけが 0 ではなく任意のµεになる。

## HX711が応答しない場合

該当CHにエラーを表示し、そのCHの処理をスキップする（他CHの処理は継続）。`8`/`s`（ゼロ点設定）でエラーになった場合、そのCHのタレオフセットは変更されず、以前の値を保持する。

## ひずみ換算

```
送信値（µε）= HX711生値 / STRAIN_SCALE
```

`STRAIN_SCALE` は `src/main.cpp` 冒頭で固定値（v3.20のデフォルト実測値 1110.0f）を暫定使用している。個体差があるため、治具のシャント抵抗による既知ひずみと実測値を比較し、必要であれば直接書き換えること。

## ハード構成

- Monita Flex ver3.20 基板（XIAO nRF52840 Sense）
- 4CHすべてに、ひずみFlexモジュール または 出荷検査治具（シャント抵抗方式）を接続
- HX711ライブラリは `lib/HX711` に同梱（bogde/HX711 0.7.5、v3.20と同一コピー）

## ビルド

```bash
cd case_other/strain_test
pio run                # ビルド
pio run -t upload      # 書き込み
pio device monitor -b 115200   # シリアルモニタ
```
