# project08_takadakikou

## 案件概要

- 顧客：高田機工（関西大学 石川先生の共同研究先・継続中）
- 対象：**SBBR最大変位計**（座屈拘束ブレース「シェイプアップブレース」用／地震後の安全性評価）の**変位測定をデジタル・遠隔化**する
- 位置づけ：レーザー変位計（ToF）＋MONITAによる遠隔モニタリングの新規開発案件
- 資料：[SBBR最大変位計 ver1（PDF）](https://www.takadakiko.com/products/bridge/earthquake/pdf/SBBR_saidaihenikei_ver1.pdf)

### 初回打合せ（2026-07-21・共同研究第8回打合せ）で出た希望仕様
1. モニタリング方法：中央の本体付き部材をレーザーで計測。防塵・結露・経年ドリフト・虫侵入対策の透明カバーで全体を覆う。バッテリー・デバイスはブレース本体内部に収める
2. チャンネル数：左右2箇所（2CH）
3. アラート送信：閾値はデバイス側でなくクラウド（スプレッドシート等）側で管理
4. 耐用年数：5年（定期点検で機器交換）
5. 通信方法：LPWA（Sigfox/LoRa）またはLTE-M。親機・子機のLoRa構成も検討
6. バッテリー：一次電池／二次電池／小型ソーラーパネルを本体内に収める構成
7. クラウド遠隔監視：Googleスプレッドシート想定（商用利用規約は要確認）
8. 測定手法：11データのメジアン値を1計測とし、50回繰り返した中央値を採用
