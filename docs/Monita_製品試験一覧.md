# Monita シリーズ 製品化のための試験一覧

- 作成: 2026-09-22（Claude 作成、Codex レビュー反映済み）
- 対象の版: Flex v3.20 / Gateway v1.21（FW 99）/ One v1.1 / Deck v1.00 / GAS gateway_common v12・one v11

## 凡例

**優先度**
- **P0（出荷停止条件）**: 満たさなければ出荷しない
- **P1（出荷前検証）**: 初回出荷前に実施する。結果によっては条件付きで出荷する
- **P2（出荷後改善）**: 量産段階や継続改善で実施する

**状態**
- ✅ 実施済み（記録あり）
- △ 一部実施、または記録なし
- ❌ 未実施
- ⛔ ファーム未実装のため、試験できない

**判定の書き方**
- 合格基準に「要定義」とあるものは、製品仕様書（B-1）で値を決めてから判定する。推測した数値は書いていない。
- 法規の欄に「要確認」とあるものは、適用されるかどうかを専門家・試験所・事業者に確認する。
- 過去の版で1回だけ成功した実績は、現行の出荷構成での「完了」には流用しない。現行版で再実施する。

## 付記: Codex レビューの反映

Codex のレビュー指摘は36件あった。そのうち、次の項目はコードで事実を確認したうえで反映した。

- One PIR の ACK 長の不整合（B-4）
- GAS one が書込失敗を黙って捨てる件（B-5）
- Gateway の上限が32台ではなく32レコードである件（G-C4）
- Sigfox 版 Flex のエラー処理の記述の訂正（B-3）

その他の指摘の反映:

- 電池の安全、保存データの完全性、完成品での EMC、人数推定の精度、ダウンリンクの競合、データ損失の定義、故障注入を、新しい項目として追加した。
