## 設計上の注意（実装で踏みやすい箇所）

### ★ EXTREF_EN を必ず立てる

本機は **REFIN = VEX/2 = 1.25 V の外部リファレンス**でレシオメトリック測定をする。
CLOCK レジスタの `EXTREF_EN`（bit6）を 1 にしないと内蔵 1.2 V が使われ、
**VEX のドリフトが相殺されなくなる**。設計の根幹が静かに失われるので、
`verifyRegisters()` のリードバック照合を必ず通すこと。

REFIN の規格は 1.1 / **1.25 typ** / 1.3 V（SBAS949A 表7-3）。VEX/2 はちょうど typ にあたる。

### ★ 1 LSB の式

要件定義 F-7 の `LSB = (2.4/Gain)/2^24` は**内蔵基準（1.2 V）の式**。
本機は外部基準 1.25 V なので **`LSB = (2.5/Gain)/2^24`** が正しい。
ゲイン32 で 1 LSB = 4.657 nV、FSR = ±39.06 mV（内蔵基準なら ±37.5 mV）。

`ADS131M06::lsbVolts()` は外部基準 1.25 V を既定にしてある。

### ★ データレートは 976.5625 SPS であって 1 kSPS ではない

`fDATA = fCLKIN / (2 × OSR) = 8.000e6 / 8192`。サンプル間隔 **1.024 ms**。
保存フォーマットに実データレートを記録すること（要件 §5.4）。

### ★ 起動順序

- **TCA9534**（F-25）：出力レジスタ 0xAA → 方向レジスタ 0xA0 の順。逆にすると P0 が一瞬 High になり VEX が入る
- **ADC**（F-26）：CS を High → CLKIN 開始 → SYNC/RESET を 256 µs 以上 Low → レジスタ設定
- **E220**（F-27）：M0/M1 を Low → `Serial1.end()` して TX を Low 固定 → Q1 OFF → 待機 → Q1 ON
  （TX のアイドル High と M0/M1 から逆給電され、電源を切ってもリセットされないため）

### ★ SPI バス共有（F-28）

ADC はモード1、SD はモード0。どちらも CPOL=0 なので SCLK のアイドルは Low で共通。
切替時は「両 CS High → SD 後は 8 クロックのダミー → `SPISettings` 切替 → 対象 CS を Low」。

## メモリ配分の見通し

| 用途 | サイズ |
|---|---|
| リングバッファ 6秒 × 6CH × 3B packed | 108 kB |
| SD 書込みバッファ（4 kB × 2） | 8 kB |
| 現状のスケッチ | 8 kB |
| **計** | **約 124 kB** / 237.5 kB |

**イベント切出し用の 90 kB コピーは持たない。** リング6秒に対し切出しは5秒なので、
発火後はリングから直接 SD へストリーミングし、1秒の余裕で追い越しを防ぐ。
`int32_t[6000][6]` にすると 144 kB になり成立しない（要件 §7.3.3・Codexレビュー指摘）。
