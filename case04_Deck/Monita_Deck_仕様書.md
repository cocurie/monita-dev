## 1. 製品概要（用途・位置づけ・システム構成図）

**用途**：橋梁 RC 床版下面の変位（たわみ）を、カンチレバー式変位センサ最大6点で**同時に**連続計測する子機。長期の静的変位監視と、車両通過時の準静的たわみ波形の収録を1台で行う。

**位置づけ**

| 項目 | 内容 |
|---|---|
| シリーズ | MONITA Deck シリーズ共通の6CH計測ユニット。単一基板・単一ファームで下表の構成に対応（要件 §1.2） |
| 対応構成 | Deck Watch L4（4CH使用・2CH予備）／Deck Watch L6（6CH）／Deck Insight H6（H型フレーム・6CH）。**Watch 標準構成と H6 型式名は未確定**（要件 §9 #8） |
| 提供価値 | 床版の**相対的な状態変化の継続監視**。絶対剛性・残存耐力・寿命の推定は対象外（製品コンセプト §2.1） |
| 形状指標（λ・ρ 等） | **研究・検証段階**。本機は生波形を残すだけで、推定はオフライン（要件 §7.3.4） |
| 従来機との違い | 従来の HX711＋MUX 順次切替（CH間 25〜45 ms 差）に対し、6CH 同時サンプリング ADC で全CHを同一時刻に取る（要件 §2.1） |

**システム構成**（要件 §1.1）

```text
床版下面
 ├ カンチレバー ×最大6（第2支持部材上）── センサケーブル 最長1.2 m・6本同一長
 ├ 【子機】Monita Deck（第2支持部材の中央）
 │    ADS131M06（6CH同時）＋ XIAO nRF52840 ＋ microSD ＋ DS3231 ＋ E220（LoRa）
 │         │ LoRa 920MHz（直線 2 m 未満）  ↑ ダウンリンク（トリガ設定・時刻）
 │         ↓ 60分ごと：静的値＋イベント統計
 └ 【親機】Monita Gateway v1.21（主桁ウェブに磁石吸着）── LTE-M ── GAS／スプレッドシート
給電：USB-C ACアダプタを親機側に置き、USB 延長ケーブルで子機へ 5 V
生波形：microSD に保存し、現地で回収（LoRa では送らない）
```

> **1.87倍問題（要件 付録A §A.3）との関係は仮説として扱う。** 既存カンチレバーの実測感度 0.927 表示µε/µm は、単純片持ち梁の理論 0.496 µst/µm の 1.87 倍。①評価した梁が実質ハーフブリッジで、表示µε が真ひずみの2倍だった、②接触子で先端が回転拘束された固定-案内梁（理論 2倍）、の2仮説がある。要件 v0.3 は評価機を1ゲージ法と記録しており①と食い違う。**どちらも未検証（試験 D-M7）。** Deck の変位出力は CH 個別校正で決まるため、この結論を待たずに計測できる。

| byte | 内容 |
|---|---|
| 0 | 0x06 |
| 1 | DeviceID |
| 2 | 子機 FW 版 |
| 3–14 | CH1〜6 変位 int16 ×6（0.1 µm/LSB） |
| 15 / 16 | 基板温度 / 外気温 int8（1 ℃/LSB） |
| 17 / 18 | 子機 RTC の時 / 分 |
| 19 | CH ステータス（bit0〜5、1＝正常） |

**イベント統計 0x07（22 B、子機→親機）**

| byte | 内容 |

| 0–2 | 0x07 / DeviceID / 子機 FW 版 |
| 3 | 集約した時（0〜23） |
| 4–5 / 6–7 | 検出件数 / 収録件数 uint16 |
| 8–13 | 振幅 p50 / p90 / p99 uint16（0.1 µm/LSB） |
| 14–19 | 正規化たわみ形状 6点 uint8（0〜255 → 0〜1） |
| 20 / 21 | 品質（0〜100）/ 連番 |

**ダウンリンク 0x82（24 B、親機→子機）**

| byte | 内容 |
|---|---|
| 0–1 | CompanyID 0xC0DE |
| 2 / 3 | 0x82 / 宛先 DeviceID |
| 4 | Flags（bit0 時刻適用、bit3 トリガ適用。Deck では両方とも常に立つ） |

**確認応答 0x83（17 B、子機→親機）**：0x83 / DeviceID / status（0＝適用、1＝拒否）/ 子機 FW 版 / 適用したトリガ設定 13 B

**トリガ設定 13 B**

| byte | 項目 | 符号化・値域 |
|---|---|---|
| 0 | 収録 | 0＝停止／1＝収録 |
| 1–2 | 閾値 | ADC コード uint16 |
| 3 | 閾値の定義 | 0＝絶対値／1＝基線から（既定）／2＝変化率 |
| 4 | 対象CH | bit0〜5（1〜63） |
| 5 | 判定方式 | 下位4bit 0＝OR／1＝AND／2＝N個以上、上位4bit＝N（1〜監視CH数） |
| 6 | 継続時間 | ms（0〜255） |
| 7 | 不感時間 | ×10 ms（0〜255） |
| 8 / 9 | プリ / ポスト | ×0.1 s（プリ 5〜30、ポスト 10 以上、合計 50 以下） |
| 10–11 | 1時間あたり最大収録数 | uint16 |
| 12 | 静的計測の周期 | 分（1〜255） |
