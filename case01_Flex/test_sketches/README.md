## 各Stepの合格基準

### Step1
- LEDが RED → GREEN → BLUE → OFF の順に光る
- シリアルに `[3V3_SW] HIGH` / `LOW` が交互に出る

### Step2
- `0x20: TCA9534` と `0x70: TCA9546A` が両方表示される

### Step3
- CH1〜CH4の切り替えログが出て `OK` が並ぶ
- テスターがあれば4052のA/Bピン電圧がログと一致する

### Step4
- `[HX711 CH1] raw: XXXXXX` が1秒ごとに出る
- ゲージに荷重をかけると値が変化する

### Step5
- CH1〜CH4それぞれの raw値が出る
- 接続していないスロットは `TIMEOUT` でOK

### Step6
- CH0〜CH3 それぞれのスキャン結果が表示される
- MPU6050を接続したCHは `0x68: MPU6050/MPU9250` が表示される
- 未接続のCHは `検出: 0個` でOK

### Step7
- CH0〜CH3 それぞれの加速度・ジャイロ・温度が3秒ごとに出る
- 接続していないCHは `応答なし` でOK
- 基板を傾けると az/ax/ay の値が変化することを確認

### Step15
- `[OK] MCP9600 検出` が表示される
- `COLD` に室温相当の値（例：20〜30°C）が出る
- 熱電対未接続時は `[WARN] オープン回路` が出てOK
- `HOT` は不定値でOK（熱電対接続後に正常値になる）

### Step16
- `[OK] ADS1115 初期化完了` が表示される
- AIN0〜AIN3 の単端入力に電圧値（mV）が出る
- DIFF 0-1 / DIFF 2-3 の差動値が出る
- 未接続ピンは浮いた値になるが raw が 0 でなければOK
- ±10V入力テストは分圧回路実装後に実施

### Step14
- `SD.begin()` が成功し、カード種別・容量が表示される
- `test.txt` の書き込み内容が読み返しで一致する
- 追記後に3行になっている
- 100行書き込みが完走し `全 Step 完了` が表示される
- 初期化失敗時は `SPI_SPEED` を `1000000` (1MHz) に下げて再試行

### Step17
- `AT` に対し `OK` が返り Sigfox モジュール準備完了と判定される
- `Device ID:` と `PAC:` にそれぞれ 8桁 / 16桁の16進文字列が表示される
- Sigfox バックエンドへのデバイス登録にそのまま使用できる
- D0 ボタン押下で再取得できる

### Step18・19（LoRa送受信テスト、2台1組で実施）
- 両方とも書き込み前に **E220のM0/M1をGNDに直結**しておくこと（Mode0=透過送受信モードに固定）
- 19（親機役）を先に起動し `[LoRa] 受信待機中...` を確認
- 18（子機役）を起動すると2秒ごとに `[TX] MONITA n` がUSBシリアルに出る
- 19側のUSBシリアルに `MONITA n` がそのまま表示されればOK（フレーム化前の生テキストがそのまま届く）
- 19側に10秒以上何も届かない場合は `[WARN] 10秒以上受信なし` が出る → 配線・電源・M0/M1・距離を確認
- 19は`MONITA `という7バイトのプレフィックスを常にスキャンしており、電波状況悪化等でバイト抜けが起きても次のメッセージから自動的に読み取り位置が復帰する（2026-07-17追加。それ以前はバイト抜け発生後、表示が永久にずれ続ける不具合があった）
- 疎通確認できたら、本番ファーム（`case01_Flex/v3.10_lora/`）のチャンネル/アドレス設定ロジックの検証に進む

### Step20（疎通不良時の切り分け）
- 実行前に **M0/M1を一時的にGND→3V3へ付け替える**（Mode3=設定モードにするため）
- 5秒おきに`ADDH/ADDL/SPED/TRANS_MODE/CHANNEL/OPTION`の現在値が表示される
- 子機・親機それぞれで実行し、**両者の値が完全に一致しているか**を見比べる
  - 一致していない場合はそれが疎通不良の原因（工場出荷設定・以前の設定が食い違っている）
  - 応答なし（`受信バイト数=0`）の場合はM0/M1が本当に3V3に繋がっているか再確認
- 検証が終わったら **M0/M1を必ずGNDへ戻す**（18/19を動かすにはMode0が必要）

### Step21（設定修正）
- Step20でREG1（送信出力）やREG3（送信方式）が異常値だった場合に使う
- 実行前にM0/M1を一時的に3V3へ接続（Step20と同じ）
- 起動時に自動で書き込み・再読み出し確認まで行う。`✓ 書き込み成功`と出ればOK
- **子機・親機の両方で実行すること**
- 完了後はM0/M1をGNDへ戻し、18/19を書き込み直して再テストする

## Step5 完了後（HX711系）

`case01_Flex/v3.02_sigfox/src/main.cpp` の本番ファームに移行。

## Step7 完了後（MPU6050系）

本番ファームの `CH_ASSIGN[]` を `2`（MPU6050）に設定して統合テストへ。
