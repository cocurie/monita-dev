# 同梱ライブラリ

## HX711/

- **出所**: bogde/HX711 **0.7.5**（v3.01 プロジェクトの `.pio/libdeps/.../HX711` からコピー）
- **理由**: PlatformIO レジストリ取得が不安定な環境でも **`pio run` できる**ようにするため
- **ライセンス**: 元リポジトリのライセンスに従う（通常 MIT）

更新手順の例: v3.01 側で `pio run` 後、当該 `HX711` フォルダを丸ごと差し替える。

## STM32duino VL53L4CD/

- **出所**: stm32duino/STM32duino VL53L4CD **1.0.5**（`case03_One/v1.1/lib` と同一）
- **改変あり**: `src/platform.cpp` の `VL53L4CD_I2CRead()` のみ。上流はアドレス送信が
  NACK の間、回数無制限に再試行するため、センサ未接続だと WDT リセットまで戻らない。
  再試行を3回に限り、失敗はエラーとして返すよう変更した（2026-09-22、週次レビュー B19）。
- **更新時の注意**: 上流版へ差し替えると上記の無限再試行が戻る。差し替えたら同じ改変を当て直すこと。
