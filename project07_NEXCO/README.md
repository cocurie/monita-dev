# project07_NEXCO

## 案件概要

### 現場について
- 場所：中国道 有野川付近
- 損傷内容：コンクリート床版下面に広範囲な剥離・鉄筋露出を確認
- 橋面はSFRCで補強済みだが、既設床版が弱く薄い状態でありSFRCとの接着が不十分な可能性あり
- 「現在はなんとかSFRCでもっているような状態」という認識
- 工事スケジュール：下り線は今年8月から、上り線は来年から床版取替工事を予定
- 工事開始までの期間にモニタリングを行い、状態把握につなげたい
- 9月に現場にマスコミが入る予定。モニタリングによる対策・可視化がプラスに働く可能性あり

### NEXCOからの宿題
「床版の抜け落ちの予兆を捉えられるようなモニタリングを、実証的にできないか」

## 測定内容

### 候補1：樹脂注入効果の計測（ひずみゲージ）
- SFRCと既設床版の間に隙間が空いている箇所への樹脂注入効果を計測
- 測定箇所：SFRC上面・界面近傍（上下）・RC下面付近
- 技術顧問コメント：重い車両が単独走行する場合、またはフィルタリング処理ができれば、おおよそのひずみ直線性（合成度合い）を把握可能。理想は静的載荷試験。

### 候補2：床版抜け落ちリスク監視（パイゲージ）
- コンクリート剥落部分に直接パイゲージを設置し、外向きに監視体制を示す
- 技術顧問コメント：曲げモーメントが最大になる中央径間中央点の下面にパイゲージを貼るのは有効な方法
