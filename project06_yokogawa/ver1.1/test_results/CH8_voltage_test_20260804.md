# ver1.1基板 CH8（±10V電圧入力）テスト結果

- 日付: 2026-08-04
- 基板: Monita Flex 横河基板 ver1.1（ブレッドボード検証）
- 対象チャンネル: CH8（ADS1115 A2-A3差動、コード上は旧「CH5 ±10V」から改称）
- テスト内容: 電圧源を約1Vステップで -10V付近 → 0V → +10V付近まで変化させ、ADS1115の応答を確認
- 結果: **正常動作を確認（OK）**。step状の入力に対してraw値・Vinともに線形に追従。
- 備考: 0V付近〜+2V付近の一部で配線が外れて反応しない区間があったため、該当データは本結果から除外している。

`Vin ≈ 1.833V, 1.758V, 1.790V, 1.763V, 0.923V, 1.791V, 1.775V, 1.897V`（ステップと無関係にばらつき、単調増加していない）

## 備考

- Vin は `GAIN_INV = 7.527`（ブレッドボード実測ベースの校正値）を用いて `Vin = ADS電圧 × GAIN_INV` で算出。
- 除外区間を除けば±1Vステップの入力に対しほぼ線形に追従しており、CH8（ADS1115 A2-A3）の回路・コードは問題なし。
