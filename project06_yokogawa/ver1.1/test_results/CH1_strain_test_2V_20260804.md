# ver1.1基板 CH1（ひずみ）テスト結果 — HX711 VCC=2V時

- 日付: 2026-08-04
- 基板: Monita Flex 横河基板 ver1.1（ブレッドボード検証）
- 対象チャンネル: CH1（HX711、ひずみゲージ）
- HX711電源電圧: **VCC=2V**（HX711データシート規定の動作範囲 AVDD=2.6〜5.5V を下回る、仕様外）
- 使用した変換係数: `raw / 1110`（現行コード `STRAIN_DISP_COEFF`）
- テスト内容: ひずみ発生装置で印加ひずみを200µεステップで変化させ、センサー出力（コード上のCH1表示値）を記録

## 回帰分析

最小二乗法でフィットすると（900µεの異常値を含む全点）：

```
出力 ≈ 0.5345 × 印加ひずみ + 71.74
```

raw値換算では概算で `raw ≈ 593 × ひずみ(µε) + 79631` に相当し、以下2点が読み取れる：

1. **ゼロ点オフセットが大きい**（無負荷でもraw≈79631相当のオフセット。タレ未実施）
2. **実効係数は約593**で、使用中の1110の約半分しかない（原点通過を仮定しても大きく非線形）

## VCC=3V時との比較

同一チャンネル・同一係数（1110）でVCCを3Vに上げて再測定した結果、印加値とほぼ1:1で追従することを確認済み（別紙: 2026-08-04 CH1 3Vテスト）。この比較により、**2V運用時の誤差はVCC不足によるHX711内部アンプ（PGA, gain128）のゲイン圧縮が原因**と推定される。HX711データシート上、AVDD=2Vは動作保証範囲外（下限2.6V）。

## 結論・注意事項

- 2V運用時の係数（実効593前後）は、そのままでは仕様外動作下でのその場限りの値であり、個体差・温度・経年変化により再現性が保証されない
- 2V運用を継続する場合、この係数をそのまま製品に採用するのは非推奨。詳細は打ち合わせ記録（2026-08-04 鶴田氏相談分）を参照
